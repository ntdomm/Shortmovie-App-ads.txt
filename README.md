## Hosting

Enable GitHub Pages for this repository:

1. Repository **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main` / `(root)`
4. Save

Project-site URL:
`https://ntdomm.github.io/Shortmovie-App-ads.txt/app-ads.txt`

> app-ads.txt is normally fetched from the **root of the developer website**
> (`https://<domain>/app-ads.txt`). A GitHub project page lives under a repository
> path. For guaranteed domain-root hosting, use a custom domain (CNAME) or a repo
> named `ntdomm.github.io`.

## Verification

Set the app's **developer website** in Appodeal / Google Play to the hosted URL
above, then verify app-ads.txt in the Appodeal dashboard.
